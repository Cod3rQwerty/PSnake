# PSnake
The game of snake - entirely within your own terminal.

## How to play
Run this command in Powershell (Windows only) :
```
iex (irm https://raw.githubusercontent.com/Cod3rQwerty/PSnake/main/snake.ps1)
```
## Controls
- Arrow Keys - Movement
- Space - Boost (toggle) **DO NOT HOLD DOWN**
- Esc - Exit
